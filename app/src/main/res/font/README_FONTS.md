# Font Setup Required

Scarica i seguenti font da Google Fonts (licenza OFL) e mettili in questa cartella come file `.ttf`:

## Space Grotesk
- [Space Grotesk Medium](https://fonts.google.com/specimen/Space+Grotesk) → `space_grotesk_medium.ttf`
- [Space Grotesk Bold](https://fonts.google.com/specimen/Space+Grotesk) → `space_grotesk_bold.ttf`

## Inter
- [Inter Regular](https://fonts.google.com/specimen/Inter) → `inter_regular.ttf`
- [Inter Medium](https://fonts.google.com/specimen/Inter) → `inter_medium.ttf`
- [Inter SemiBold](https://fonts.google.com/specimen/Inter) → `inter_semibold.ttf`

I file XML `space_grotesk.xml` e `inter.xml` fanno già riferimento a questi nomi.

Dopo aver aggiunto i `.ttf`, il build funzionerà correttamente.
